# PHP: La Guida Completa - Code Listings

Companion repository for the code examples extracted from `PHP: La Guida Completa` and its English and Spanish editions.

The repository is organized by edition and manuscript source file:

- `it/` - Italian edition
- `en/` - English edition
- `es/` - Spanish edition

Each manuscript source file with code has its own Git tag, for example `chapter-18` or `appendix-php85-checklist`. Book links point to the file at the tag that introduced that group of listings, so examples remain stable even if later chapters are added or revised.

The full machine-readable listing map is in `manifest.json` on `main`.
